📋 Product List

📥 Store SKU / Excel File Upload

Upload CSV, TSV, Excel (.xlsx/.xls) or text file. Large SKU lists (including 100,000+ rows) are processed with indexed matching and batched cloud uploads. Actual limits depend on file size, phone/browser memory, Supabase plan, and database/API limits. The tracker reads product name, SKU, barcode, and Stock/Quantity if available. Stock is optional: if the file has a stock column, its value updates the product stock; if it has no stock column or the cell is blank, existing stock is preserved and new products start at 0. Missing fields can be completed later using Edit. Existing products matched by SKU/barcode—or by exact product name when identifiers are absent—are updated rather than duplicated. Re-uploading the same list should not increase the product count.
