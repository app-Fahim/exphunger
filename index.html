📄 Upload SKU File

Upload an Excel (.xlsx, .xls) or CSV file. All worksheets and non-empty rows are processed. Product Name is detected automatically where possible; other columns are preserved in Notes. SKU, Barcode, Stock and Expire/Expiry Date are optional. Missing columns will not stop the file import. If Stock is missing, existing stock is kept (or 0 for a new product).

Stock import mode: Update matching products only
The system matches products using SKU first, then barcode, then product name. For matching products, a positive Stock/Qty value (e.g. 20, 15, or +20) is added to current stock; a negative value (e.g. -15) is subtracted from current stock; 0 resets stock to zero. Stock cannot go below zero. Products not present in the file remain unchanged. If the file has no Stock/Qty column, stock is not changed.
Recommended columns: Product Name, SKU, Barcode, Stock, Expire. Only Product Name is required; SKU, Barcode, Stock and Expire are optional. The file will still import if any or all of those optional columns are missing. Use one product per row and keep the first row as the column headings. You can add your own columns too; their values are saved in Notes. Sample files below show the expected format.
